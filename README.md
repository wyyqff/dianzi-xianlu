## 阅读约定

- **加粗**标出定义、判据和关键结论；核心公式单独成行。
- **△** 标出经验近似、仍需结合器件或课堂语境判断的内容。
- 直流静态量使用大写符号，如 $I_{CQ}$；交流小信号量使用小写符号，如 $i_d(t)$；瞬时总量可写作 $i_D(t)=I_{DQ}+i_d(t)$。
- 电压下标说明参考方向，例如 $U_{CE}=V_C-V_E$。公式的适用条件放在相邻正文中。
- 原课堂图片保留，规范公式和说明可在图片附近阅读。参考链接放在各页末尾。
